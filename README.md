# Seashell — Ocean-based Handmade Art from Azerbaijan

Official website for **Seashell MMC** (by Aydan Zohrabqizi) — handmade seashell mirrors,
ocean resin art, shell mosaics and artisan gifts, shipped worldwide.

## Features
- Minimal, editorial single-page design
- Multi-language: **EN / AZ / RU**
- Product shop with a WhatsApp order basket
- Autoplay craft videos (process & studio)
- Story, process, gallery, location (Google Maps) sections
- Fully responsive

## Tech
Plain **HTML / CSS / JavaScript** (no build step). Just open `index.html`.

```
seashell-new/
├── index.html
├── css/style.css
├── js/ (i18n.js, main.js)
└── assets/ (logo, product images, videos)
```
